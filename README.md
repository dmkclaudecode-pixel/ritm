# Rhythm

Личный планировщик недели: движение, сон, дневной свет, общение и отдых. Показывает, чего не хватает до целей недели, и напоминает через календарь телефона.

Работает полностью на телефоне: данные хранятся в браузере, приложение открывается без интернета. Установка на Android: откройте сайт в Chrome и выберите «Установить приложение».
