# Rhythm — памятка для разработки
- Язык общения с владельцем и интерфейса: русский, коротко.
- Прочитай `ARCHITECTURE.md`: слои, формат данных, правила и план рефакторинга. Держи его в голове в каждой задаче.
- Перед коммитом: `npm run lint` и `node tests/run.js` зелёные (CI проверяет то же). Новая логика — чистыми функциями (`core.js`) с тестами; в `js/*.js` не наращивать логику без нужды (app.js больше нет — он разрезан на `js/`).
- Новый файл → `index.html`, `sw.js` SHELL (`js/*.js` копируется в APK маской, корневые файлы — в `android.yml`). Поднимать версию кэша в `sw.js` при каждом релизе.
- Релиз: коммит в `main`, `git push origin main main:gh-pages`, дождаться CI, отправить ссылку на APK (`releases/latest/download/ritm.apk`).
- При каждой правке `js/*.js` выносить по возможности чистую часть в модуль (следующий шаг плана: `storage.js`).
- Модули `js/*.js` — ES-модули: зависимости только через `import`, код запуска — в `init()` (см. ARCHITECTURE.md, раздел «Как добавлять код»).
