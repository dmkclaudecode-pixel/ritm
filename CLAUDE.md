# Rhythm — памятка для разработки
- Язык общения с владельцем и интерфейса: русский, коротко.
- Прочитай `ARCHITECTURE.md`: слои, формат данных, правила и план рефакторинга. Держи его в голове в каждой задаче.
- Перед коммитом: `node tests/run.js` зелёный. Новая логика — чистыми функциями (`core.js`) с тестами; в `app.js` не наращивать логику без нужды.
- Новый файл → `index.html`, `sw.js` SHELL, `android.yml` (cp). Поднимать версию кэша в `sw.js` при каждом релизе.
- Релиз: коммит в `main`, `git push origin main main:gh-pages`, дождаться CI, отправить ссылку на APK (`releases/latest/download/ritm.apk`).
- При каждой правке `app.js` выносить по возможности чистую часть в модуль (следующий шаг плана: `storage.js`).
