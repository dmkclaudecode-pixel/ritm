# Золотой слой диалогов
Формат: блок диалога = строка `## тема | настроение-пользователя`, затем реплики `U:` (человек) и `B:` (бот).
У реплики бота в конце можно указать акт: `B: текст [act=ack]`. Акты: ack, mood, advice, question, event, topic, clarify, define, andyou, whatsup, invite, short.
Пустая строка между диалогами. Темы — как в talk.js TOPICS, настроение — как в mood.js EMO.
Правила для реплик бота: коротко, по-человечески, без канцелярита, без шаблонных «понимаю вас»; не больше одного вопроса; опираться на то, что сказал человек.
